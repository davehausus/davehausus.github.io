# Design Approach
<TwoCol>
<Block title="Touch-first interaction">

The UI was built around quick, thumb-friendly gestures:

- Large stat buttons for rapid tapping
- Shot chart interface with instant placement
- Clear visual feedback to confirm every action

This allowed users to track plays without taking their eyes off the court.

</Block>

<Block title="A visual system that supports speed">

The design focused on reducing noise:

- Clean typography that’s readable from a distance
- High-contrast color coding for quick stat recognition
- Thoughtful spacing that prevents accidental taps

Every screen was optimized for **fast decision-making**.

</Block>
</TwoCol>



# Brand identity that reflects Motion + Precision
I designed a brand that feels athletic and modern, energetic yet minimal. The identity supports the product without overpowering it, allowing the data to remain the hero.

# Outcome
The result is an app that gives everyday athletes and coaches the analytical tools typically reserved for professionals, without overwhelming them.

Athlytix proves that powerful tools don’t need complex interfaces. With the right hierarchy, motion, and clarity, even advanced stat tracking becomes simple.

<br />

# Reflection

Designing for speed teaches you to remove friction everywhere:
- Fewer taps
- Clearer paths
- Cleaner visuals
- Smarter defaults

Athlytix became a project that reinforced one of my core design beliefs: <br />**if the interface slows you down, it's broken.**
