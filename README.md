# David de Jesús · Portfolio

The source code for [daviddejesus.me](https://daviddejesus.me), the personal portfolio of **David de Jesús, Senior Product Designer**.

The site brings together product design case studies, motion-driven interfaces, interaction design, Rive experiments, and selected work from across my design practice.

## About

This portfolio is designed and built as part of my own product design practice. It is an ongoing space for experimenting with interaction, motion, responsive design, and new ways of presenting design work on the web.

The site currently includes several different technologies and projects:

* **HTML & CSS** for the original portfolio experience
* **Astro** for the portfolio blog and content-driven pages
* **Starlight** for structured documentation and design systems
* **Rive** for interactive motion and state-driven interfaces
* **GitHub Pages** for hosting and deployment

The repository contains both the production portfolio and the newer systems being developed alongside it.

## Structure

The project includes:

* **Portfolio**: the main personal website and selected work
* **Blog**: articles, tutorials, and experiments from The Workshop
* **Work**: product design case studies collected in In Practice
* **Systems**: documentation and design system explorations built with Astro and Starlight
* **Motion**: Rive experiments and interactive interface prototypes

## Design approach

The portfolio reflects my focus as a Senior Product Designer:

**Product design · Interaction · Motion · UI systems · Prototyping**

Motion is treated as part of the product experience rather than decoration. I use tools such as Rive to explore state, behavior, feedback, and interaction in ways that static design files cannot always communicate.

## Development

The site is primarily a static website, with different parts of the project using the tools best suited to their purpose.

For local development, navigate to the relevant site directory and follow its project instructions.
