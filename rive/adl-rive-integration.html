🔧 How to Set Up Your Rive Animation

Step 1: Create Properties in Rive View Model

In your Rive file, create a View Model with these properties:

  • activityName (String) - The name of the current activity
  • activityType (Number) - Activity type code (0-6)
  • activityIcon (String) - Emoji icon for the activity

Activity Type Codes:

  • 0 = Sleeping 😴
  • 1 = Eating 🍽️
  • 2 = Showering 🚿
  • 3 = Bathroom 🚽
  • 4 = Medication 💊
  • 5 = Social 👥
  • 6 = Resting 🪑

Step 2: Create State Machine Conditions

In your State Machine, create different states/animations for each activity type:

  • When activityType == 0 → Show sleeping animation
  • When activityType == 1 → Show eating animation
  • When activityType == 2 → Show showering animation
  • And so on...

Step 3: Add Your Rive File

Replace the placeholder section in the HTML with:

<canvas id="riveCanvas" width="400" height="400"></canvas>

Then uncomment the Rive initialization code at the bottom of the script section.

Step 4: Test the Integration

Once your Rive file is added:

  • Click "Start Simulation"
  • Watch as activities change throughout the day
  • Your Rive animation should respond to each activity change
  • Adjust the speed slider to test faster

Step 5: Deploy to GitHub Pages

This is a static HTML file - just:

  • Create a GitHub repository
  • Upload this HTML file and your .riv file
  • Enable GitHub Pages in repository settings
  • Your simulation will be live with zero hosting costs!
